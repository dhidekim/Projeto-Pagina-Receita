# Página de Receita

Uma landing page de uma receita de cupcake de café com chantilly, desenvolvida em HTML e CSS.

## Sobre o projeto

Este projeto é uma página estática inspirada em receitas culinárias, com foco em apresentação visual elegante e em uma estrutura simples e responsiva. A página inclui:

- imagem principal da receita;
- título e descrição da receita;
- informações de tempo, rendimento e dificuldade;
- lista de ingredientes;
- instruções de preparo;
- rodapé com mensagem final.

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts

## Como visualizar o projeto

1. Abra a pasta do projeto no navegador de sua preferência.
2. Clique no arquivo `index.html`.
3. Ou execute um servidor local simples, se preferir, por exemplo:

```bash
python -m http.server 8000
```

Em seguida, acesse:

```text
http://localhost:8000
```

## Personalização

Você pode alterar:

- textos da receita em `index.html`;
- cores, espaçamentos e fontes em `style.css`;
- imagens da pasta `assets/`.
